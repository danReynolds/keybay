# Historical device security receipts

This directory preserves evidence produced by Keybay's superseded
release-subject receipt model. It is historical input only: current release
tooling does not consume it, and it must not be generalized beyond the source,
configuration, scenarios, and limitations it records.

New physical runs will produce source-commit-scoped qualification reports for
review in GitHub issues. Raw logs remain private and ephemeral. The historical
files stay unchanged until a fresh report replaces their remaining evidentiary
value; Git history will preserve them after removal from the active tree.
