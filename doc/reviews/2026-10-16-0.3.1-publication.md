## Bundled OpenSSL

The first 0.3.1 stage bundled Homebrew OpenSSL 3.6.3 on macOS. That version
predates the September 29, 2026 advisory, which fixed elliptic-curve timing
side channels on ARM64. Hardware-key unlock uses elliptic-curve operations.

Before publishing, the build host's `openssl@3` was upgraded to 3.5.9. Homebrew
now tracks the 3.5 LTS line, and 3.5.9 carries that advisory's fixes. The macOS
archive was then re-staged and bundles OpenSSL 3.5.9 (29 Sep 2026). The Linux
archives bundle Ubuntu 22.04's `libssl3` `3.0.2-0ubuntu1.30`, the current
package for that release at build time.
